# To-Do List Application

একটি সম্পূর্ণ to-do লিস্ট অ্যাপ্লিকেশন যা local storage এ ডেটা সংরক্ষণ করে।

## 🎯 ফিচার

- ✅ **নতুন টাস্ক যোগ করুন** - সহজেই নতুন কাজ যোগ করুন
- ✅ **টাস্ক সম্পূর্ণ করুন** - চেকবক্স দিয়ে চিহ্নিত করুন
- ✅ **টাস্ক ডিলিট করুন** - অপ্রয়োজনীয় কাজ সরান
- ✅ **ফিল্টার ফাংশনালিটি** - All, Active, Completed দেখুন
- ✅ **স্ট্যাটিস্টিক্স** - মোট, সক্রিয় এবং সম্পূর্ণ টাস্ক গণনা
- ✅ **Local Storage** - ব্রাউজার বন্ধ করলেও ডেটা থাকে
- ✅ **রেসপন্সিভ ডিজাইন** - সব ডিভাইসে কাজ করে
- ✅ **আধুনিক UI** - সুন্দর এবং ব্যবহারকারী-বান্ধব

## 🚀 শুরু করুন

### ব্যবহার করা সহজ - শুধু ওপেন করুন:

1. `index.html` ফাইল ব্রাউজারে খুলুন
2. সরাসরি ব্যবহার শুরু করুন - ইন্সটলেশনের প্রয়োজন নেই!

## 💻 ব্যবহার গাইড

### নতুন টাস্ক যোগ করুন
1. ইনপুট ফিল্ডে টাস্ক লিখুন
2. "Add Task" বাটন ক্লিক করুন বা Enter চাপুন
3. টাস্ক লিস্টে যুক্ত হবে

### টাস্ক সম্পূর্ণ করুন
- চেকবক্সে ক্লিক করুন
- টাস্ক লাইন-থ্রু স্টাইলে দেখা যাবে

### টাস্ক ডিলিট করুন
- "Delete" বাটনে ক্লিক করুন
- নিশ্চিতকরণের পরে মুছে ফেলা হবে

### ফিল্টার করুন
- **All** - সব টাস্ক দেখুন
- **Active** - শুধু সক্রিয় টাস্ক
- **Completed** - শুধু সম্পূর্ণ টাস্ক

### পরিষ্কার করুন
- **Clear Completed** - সম্পূর্ণ টাস্ক মুছে ফেলুন
- **Clear All** - সব টাস্ক মুছে ফেলুন

## 🔧 প্রযুক্তি

- **HTML5** - মার্কআপ
- **CSS3** - স্টাইলিং এবং অ্যানিমেশন
- **Vanilla JavaScript** - কোন ফ্রেমওয়ার্ক নেই
- **Browser Local Storage** - ডেটা সংরক্ষণ

## 💾 Local Storage

অ্যাপ্লিকেশনটি ব্রাউজারের local storage ব্যবহার করে ডেটা সংরক্ষণ করে:

```javascript
// Todos JSON ফর্ম্যাটে সংরক্ষিত:
[
    {
        id: 1623456789,
        text: "Buy groceries",
        completed: false,
        createdAt: "2026-06-09T..."
    },
    ...
]
```

### Storage Location:
- প্রতিটি টাস্ক `todos` কী এর অধীনে সংরক্ষিত
- ডেটা ব্রাউজার বন্ধ করলেও থাকে
- একই ব্রাউজারে সব ট্যাব সিঙ্ক থাকে

## 🎨 ডিজাইন বৈশিষ্ট্য

- **গ্র্যাডিয়েন্ট ব্যাকগ্রাউন্ড** - আধুনিক লুক
- **অ্যানিমেশন** - মসৃণ ট্রানজিশন
- **ডার্ক/লাইট থিম সাপোর্ট** - ব্রাউজার সেটিংস অনুযায়ী
- **মোবাইল অপটিমাইজড** - ফ্লুইড লেআউট

## 📊 স্ট্যাটিস্টিক্স

রিয়েল-টাইম গণনা:
- **Total** - সব টাস্ক সংখ্যা
- **Active** - বাকি কাজের সংখ্যা
- **Completed** - শেষ হওয়া কাজের সংখ্যা
