# Medicare Billing App

একটি অনলাইন মেডিকেয়ার বিলিং সিস্টেম যা প্রোডাক্ট, MRP, DP এবং কারেন্ট প্রাইস ম্যানেজ করে।

## প্রযুক্তি স্ট্যাক
- **Frontend**: React, HTML/CSS/JavaScript
- **Backend**: Node.js/Express
- **Database**: PostgreSQL

## ফিচার
- প্রোডাক্ট ম্যানেজমেন্ট
- বিলিং সিস্টেম
- প্রাইস আপডেট
- ইউজার অথেন্টিকেশন
- রিপোর্ট/অ্যানালিটিক্স
